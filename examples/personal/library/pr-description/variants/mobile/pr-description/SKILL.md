# Pull request descriptions

Write the description in four short sections, in this order:

- **What**: one or two sentences on what the change does.
- **Why**: the problem it solves, with a link to the ticket.
- **Testing**: how you checked that it works. Name the app version, the platforms (iOS,
  Android), and the devices or simulators you tested on.
- **Screenshots**: before and after, side by side, for any change to what a user sees. Keep
  each image under 1 MB.

Keep the whole description under 200 words, and don't paste the diff.
